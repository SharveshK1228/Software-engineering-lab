# Software Engineering Lab 5–7 submissions

The SRN-specific workbook rows assign Lab 5 to the radio schedule program and Labs 6–7 to the hotel booking program.

- [Lab 5](Lab-5/): static analysis findings, fixes, before/after reports, reflection, and focused unit checks.
- [Lab 6](Lab-6/): hotel booking coverage tests and line/branch coverage reports.
- [Lab 7](Lab-7/): Hypothesis fuzz tests and hardened input parsing functions.

Validation was run with Python 3.12. Test output and coverage summaries are included with the lab files.
